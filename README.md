# py_iskola

Iskolai Python órai anyagok, gyakorlás és a végső beadandó feladat.

A programot Visual Studio Code programban készítettem, Python 3.13-mal, Debian Linux környezetben.

Ez a git a következőket tartalmazza:

- Beadando: a féléves beadandó leírás a mappában lévő README-ben
- Gyakorlas: első órai gyakorlások
- Osztaly: osztályok, autóverseny órai bemutató volt
- WebApplication: dobókocka statisztika órai bemutató volt
